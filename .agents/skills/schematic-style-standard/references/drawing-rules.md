# V3系標準の作図規約 — 実装と例外

## 1. 機能ブロックと電源の流れ

- 主信号の理解しやすい方向を優先。入力→処理→出力を左から右に配置するのが基本。
- 電源系は根元の入力→各電源生成IC/スイッチ→出力という**実際の系統に基づいたツリー**とする。見た目のために実際と違う直列関係を表現しない。
- LDOのFB抵抗・切替、EEPROMのプルアップ、RESET RC、LEDと直列抵抗など、局所的な機能回路は実線で分かるようにする。
- ブロックを整理する過程で、不要な空白があればコンパクト化。ただし文字・配線・機能区分が詰まりすぎる場合は余白を残す。

## 2. GND・電源記号・FLAG

- GNDは部品近くで短くまとめ、原則として下向き三角GND記号を使う。近接する**同一ネット**のGND端子は局所で結線してよい。
- 各種電源は名前付きの統一記号で示す。V3系の○＋横棒形は好みのスタイルでありCAD標準ではない場合はプロジェクトローカルライブラリに実装する。既存の電源記号やERCを破壊しない。
- **PWR_FLAGは上向き**。配線上に置くときは線分と記号が重なって記号が判読できなくならないようにする。「上向き」は図面上の見た目に基づき検査し、CADの角度値だけで誤判定しない。
- 電源経路のPWR_FLAGと下向きGND記号を見間違える配置を避ける。PWR_FLAG自体は電源供給元の存在をERCへ知らせるための部品記号であり、実際に電圧が供給されるかの保証ではない。

## 3. 受動部品と配置意図

- 電源や信号のシャントパスコンは**縦向き**。電源/信号側が上、GNDが下。電気的にはシャント（並列）であり電源線へ直列にしてはならない。
- ICの入力パスコンは供給元→C接続点→IC入力の順で読める構成。**近接化を理由に横向きにしない**。必要ならICピンから少し離す。
- 水晶の負荷容量も同じように機能と端子の関係を追いやすくし、通常は下にGND。発振回路の参照抵抗、RESET RCなどを不必要にICから離さない。
- ESD保護素子を信号線の近くに置き、信号からの枝とGND線を短く描く。これらはPCBでの低寄生/低インピーダンス配置の意図を示すが、図面上の長さを実装品質の証明としない。
- フェライトビーズの絵はコイル形状を原則にする。部品識別（FB）や電気的な意味を失わない。型番・値・ピンの接続とフットプリントを保護。

## 4. ネットラベル、バス、交差

- 同一ブロックでは接続をなるべく実線で追えるようにする。ただし無意味な長距離配線は、ブロック間のラベルで省略してよい。
- 他の場所とラベルで接続するときは、原則として部品ピンから短い線を引き、**その先端にラベルを付ける**。文字がピンやシンボルに密着しないようにする。線は実際にはネットに属しており、未接続として扱わない。
- USB D+/D−のような差動対は主な区間を近接して並走。間隔は隣接ピン間隔を作図上の目安とし、自然な屈曲・ファンアウトで調整する。差動対の**不要な交差を減らす**。交差0は絶対要件ではなく、短い保護分岐・見やすさ・配置の妥当性と比較して判断する。
- XTAL_IN/OUTも関連2信号として視覚的にまとまるよう描く。ただし電気的にはUSBの差動信号とは別。
- UARTなどの線が上下位置を入れ替えるために、はっきりした非接続クロスを作るのは許容する。**交差数の少なさより対応関係の分かりやすさを優先**する。
- バスは関連信号が多く長距離になる場合に使用を検討。無理にバス化しない。KiCadなどCAD固有の接続規則に従う。

## 5. 重なり・余長の防止（HARD＋PREFERENCE）

**HARD：**

- **線分の重複禁止**：同じ端点を持つwireの重複登録、同一直線上の一部区間が二重に描かれている状態、同ネットであっても視認性・CAD状態を損なう余分な線分は残さない。
- **見間違う重なりを残さない**：wireがシンボルの文字やPWR_FLAG、ネット名の文字列を不適切に覆う状態、未接続の信号なのにジャンクションで接続されているように見える状態は禁止。シンボルの端子で正式につながるための接触は例外。
- **分岐の可視性**：接続するT分岐には適切なジャンクションを示し、交差だけの非接続には不要なジャンクションを付けない。

**PREFERENCE：**

- 必要のない長い往復、遠回り、折返し、複数の交差は削減する。部品が近接可能なら部品を寄せ、配線を縮める。
- ただし長さの単純最小化で、局所機能の関係が失われるなら無理に短くしない。USBの上辺迂回は以前のユーザーレビューで許容されていた。回路図上の長さをPCBの伝送特性へ読み替えない。
- ある経路を短くすると別の経路が長くなる場合は、回路の機能と可読性を優先し、変更と理由を図面や報告に記録する。

## 6. 表示

- シンボルのすぐ近くにRefとValueを横書き。原則Refが上、Valueが下。部品と文字をセットで移動する。
- コンデンサは横にRef/Valueをまとめて配置。同種部品で一貫性を持たせ、向き・縦位置をそろえる。
- LEDの矢印・コイル・端子・配線・GND・PWR_FLAG・注記が文字と重なる場合はシンボルと周囲配置を調整。**文字だけを離れた場所へ逃がさない**。
- レビュー用A2/A3等は全体構成と拡大時の読解性を両方確認。必要に応じてページ構成を設計規模に合わせる。
