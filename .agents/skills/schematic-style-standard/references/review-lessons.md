# A-2レビュー由来の作図上の教訓

**出典範囲**：`docs/reviews/review_register.md`（2026-11-22、R-0001〜R-0015）、`docs/reviews/batches/`、A-2 V0→V3-polishと、その後の設計変更ブランチ。以下は将来の作図に再利用するための**規約候補**であり、回路の電気的な設計変更そのものを自動実施する指示ではない。

| 参照 | 観察された課題/改善 | 一般化した作図ノウハウ |
| --- | --- | --- |
| V1/V2 | ネット名だけでは局所回路を理解しづらい | 帰還・RC・保護・フィルタは機能ごとに配置し、局所の実線接続を見せる |
| V3 | GNDが不必要に長い、電源系統が追いづらい | 近接GNDと記号、電源ツリー、各電源名の明示 |
| V3-refine | D1の長い枝、パスコンの分散、FB図形 | 保護素子・パスコンを対応する信号/電源ピン近傍へ。FBをコイル図形へ |
| V3-polish | パスコンをピンに寄せすぎて横置き・文字離れ | **縦置き＋GND下側＋部品表示の近接を優先**し、配置距離は次善 |
| R-0009 | C3と入力電源への接続がL字型で分かりづらい | 電源記号→コンデンサ接続点→ICピンの順が見える並列シャント表現 |
| R-0010 | USB5Vのパスコンも同じ問題 | 電源種に依存せずパスコンの入力/出力経路を確認 |
| R-0011 | PWR_FLAGに配線が重なり判読不能 | **wireとPWR_FLAG・文字の不適切な重複を許さない** |
| R-0012 | USB・XTALの関連2本に不要な交差 | **ペア経路の交差最小化**（水晶2→0交差、USB3→1交差の記録）。クロス絶対禁止ではない |
| R-0013 | 電源ブロックに不要な大きな空白 | 電源・FB・スイッチを適度にまとめ、全体と局所の両方で読みやすくする |
| R-0014 | RESET_NのR2/C22がU1から遠い | 同じRC機能の部品をIC端子近くへ寄せ、対応関係を実線で追えるようにする |
| R-0015 | 下向きPWR_FLAGが下向きGNDと似る | **PWR_FLAGは上向きに統一**。接続点とERCを維持して向きだけ調整 |

レビューから得た技術的な回路設計知識（ESD素子、FT232H内蔵3.3 V、負荷容量、DNP、USB5Vの制御など）は、**回路設計スキル**の候補として別管理する。今回の作図スタイルには、データシートに基づかない型番・定数変更を含めない。
