# JLCPCB に発注する

業者を問わない確認事項 (製造能力の確かめ方、極性、3D モデル、在庫など) は
`README.md`。ここは JLCPCB に固有のことだけ。`make fab FAB=jlcpcb` (既定) で
`out/jlcpcb/` に出る。

## 3 つのファイル

| ファイル | 列 |
| --- | --- |
| ガーバー zip | 製造レイヤとドリル |
| BOM | `Comment,Designator,Footprint,LCSC Part #` |
| 実装座標 | `Designator,Mid X,Mid Y,Layer,Rotation` |

2 層のガーバーのレイヤ (4 層なら `In1.Cu,In2.Cu` が足される)。

```
F.Cu,B.Cu,F.Paste,B.Paste,F.Silkscreen,B.Silkscreen,F.Mask,B.Mask,Edge.Cuts
```

## 製造能力

`jlcpcb-4layer.kicad_dru` に 4 層・外層 1oz の下限を規則として書いてある。
当て方は `README.md`。

| 項目 | 下限 |
| --- | --- |
| 線幅 / 間隔 | 0.09 mm (2 層は 0.1、2oz は 0.15) |
| 異ネットの SMD パッド間 | 0.15 mm |
| ビア 穴 / 径 | 0.15 / 0.25 mm (2 層は 0.3 / 0.45) |
| PTH 穴 / アニュラリング | 0.15〜6.3 mm / 0.15 mm (推奨 0.2) |
| NPTH 穴 | 0.5 mm |
| 穴間 (ビア / パッド) | 0.2 / 0.45 mm |
| 穴と配線 (ビア / PTH) | 0.2 / 0.28 mm |
| 銅と基板端 | 0.2 mm |
| ソルダマスクのブリッジ | 0.1 mm |
| シルク 線幅 / 文字高さ / パッドとの間隔 | 0.15 / **1.0** / 0.15 mm |

数値は 2026-09 に公式の製造能力ページで確かめたもの。変わることがあるので、
発注前に `https://jlcpcb.com/capabilities/pcb-capabilities` を見る。

## 安く抑える

見積もりで一番大きくなりやすいのは**拡張コンポーネント料**。基本部品 (Basic) と
推奨部品 (Preferred) 以外は 1 種類あたり約 $3 かかる。個数ではなく種類で数えるので、
同じ値の部品を 2 か所で別型番にしていると 2 回取られる。

- 受動部品は、値が同じ基本部品に寄せる。jlcsearch の `is_basic` / `is_preferred` で探す
- C0G を X7R にしてよいのは、フィルタやスナバのように容量のずれが効かない所。
  発振の CT やタイミングは温度で周波数が 1 割ほど動くことを承知で替える
- E96 の半端な値 (15.4k など) は基本部品に無いことが多い。E24 に寄せて計算し直す
- 耐圧や DC バイアスで決めた電源のコンデンサは替えない。基本部品は X5R・小型しか
  無いことが多く、実容量が大きく落ちる
- 端子台やピンヘッダは拡張部品料とはんだ付け料が両方かかるので、自分で付けるほうが
  安い (`HAND_SOLDER`)

部品を替えるときの注意 (パッケージが変わってベタから外れる、など) は `README.md`。

## 設定で間違えやすいところ

**発注番号の印字**。位置を指定しないと勝手な場所に入る。露出銅や
アンテナの上に来ると困る。

**回転角**。EasyEDA 由来のフットプリントなら JLCPCB のライブラリと同じ向きに
なるはずだが、アップロード後のプレビューで IC と極性部品の 1 番ピンを見る。
