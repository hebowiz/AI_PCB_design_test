# 4 層・内層 GND 面の基板を自動配線で仕上げる

内層 2 枚を GND 面、表裏を部品と信号にする構成を、Freerouting で完走させる手順。
設定の見本は `examples/dcdc-4layer/finish.py`、実装は `scripts/finish_board.py`。

## 工程

```
ato build → dedupe_uuids → 配置 → pre → 配線前 DRC → unroute → DSN → 配線
          → SES → post → DRC (未接続 0 まで pre からやり直す) → ガーバー
```

pre と post の中身は次のとおり。どちらも「前回足したものを消して足し直す」形にして、
何度流してもよいようにする。

| 段 | 足すもの |
| --- | --- |
| pre | 4 層化、取付穴、F.Cu のベタ (電源系)、内層の GND 面、固定配線と固定ビア、GND ファンアウト、配線中だけの禁止領域 |
| post | 禁止領域を外す、ルータ出力の掃除、表裏の GND ベタ、ステッチングビア |
| labels | シルクの部品番号を 1.0mm にして部品に隠れない位置へ (`scripts/place_labels.py`) |

## 内層は電源層にする

`SetLayerType(In1_Cu, LT_POWER)` にすると DSN で `(type power)` になり、ルータは
内層に信号を引かない。GND 面は内層いっぱいのゾーンとして pre で置く。これは DSN に
面として載り、ビアが面に届けば接続済みと見なされる。

**表裏の GND ベタは post で置く**。配線前にあると、ルータが信号の通り道を失う
(2 層のときと同じ)。

## GND はルータに任せない

表面実装の GND パッドを 50 個ほど持つ基板で任せると、各パッドから内層へのビアを
打ちきれず、数十本の未配線が残る。pre で**パッドごとに直近へビアを打ち、短い線で
繋いでロックする** (ファンアウト)。ビアの位置は、パッドの外向き 8 方向と距離を
順に試し、次のどれにも当たらない最初の点を選ぶ。

- 他ネットのパッド (外接矩形 + クリアランス)。引き出し線の途中も調べる
- 固定配線、固定ビア、既に打ったビア
- 電源系ベタの輪郭の中と縁の近く
- 基板の縁と取付穴

両隣を他のピンに挟まれて出口の無い GND ピン (0.5〜0.65mm ピッチの IC の中央ピン)
は、IC の腹の下を通して、同じ IC の別の GND ピンへ固定配線で繋ぐ。

## 電源系のベタと、そこからの枝

電源系 (入力、スイッチノード、出力など) は F.Cu のゾーンを多角形で直接書く。
ルータはこれを障害物として扱わないので、配線の間だけ同じ輪郭の禁止領域を重ねる
(`routing.md`)。

ベタのネットでベタの外にあるパッド (分圧抵抗、小電流の電源入力) は、ルータが
ベタから引けない。ベタの縁に 0Ω を置き、片方のパッドをベタの中に入れて、
先を別ネットにする。

## 固定配線で決めるもの

ルータに任せると形が決まらない、または引けない線は pre で固定配線にしてロックする。
ロックした線は DSN で `(type fix)` になり、ルータは触らない。

- ケルビン接続 (シャントのパッド内側から並走)
- ゲート駆動のような短く太くしたいループ
- 挟まれて出口の無いピンからの脱出
- **層を変えたい長い線**。禁止領域で B.Cu に追いやると SES から落ちるので、
  上下にビアを置いた B.Cu の固定配線にする。ルータは両端のビアに繋ぐだけになる

固定配線は `(ネット, 幅, [点...], 層)` の表にして、座標は配置表と一緒に直す。
**配置を変えたら固定配線の座標も必ず見直す**。ずれた端はパッドに届かず、
配線前の DRC でも見つからない (ルータが残りを引いて誤魔化すことがある)。

## 配線前に DRC を回す

配線は 1 回 5〜9 分かかる。その前に DRC を回し、次の種類だけを見る
(禁止領域の中の固定配線や、未配線のビアは配線前なので無視してよい)。

- `clearance`, `shorting_items`, `solder_mask_bridge`: 部品の重なり、固定配線やビアの位置ずれ
- 自分の部品のパッド同士の `clearance`: ネットクラスがピン間隔より大きい

これが 0 でないまま配線すると、ルータは黙ってその接続を諦める。

## 仕上げの確認

```sh
make drc                                    # エラーの違反 0、未接続 0
$(scripts/kicad_python.sh) scripts/check_overlap.py board.kicad_pcb
$(scripts/kicad_python.sh) scripts/netlist_diagram.py board.kicad_pcb docs/netlist.md bom.csv
```

`netlist_diagram.py` は 1 ピンだけのネットを最後に列挙する。意図した開放 (未使用の
UVLO 設定ピンなど) か、繋ぎ忘れかを 1 本ずつ確かめる。
