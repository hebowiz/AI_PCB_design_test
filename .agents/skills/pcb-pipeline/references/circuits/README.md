# 回路の種類ごとの知見

部品の配置と配線の形は回路の種類で決まり、ルータはそれを知らない。
形が効く所は、配置表と `board/finish.py` (固定配線、ベタ、禁止領域) で先に決める。

| ファイル | 回路 | 元の基板 |
| --- | --- | --- |
| `power.md` | スイッチング電源 | 降圧 DC-DC、4 層 (`examples/dcdc-4layer/`) |
| `low-current.md` | 微小電流・高インピーダンス | ドーナツ電極の微小電流計、2 層 (`examples/electrode-2layer/`) |

## ここに無い種類を足す

ここに無い種類の回路を含むなら、配置を決める前に調べる。調べる先は、
使う IC のデータシートの "Layout guidelines"、評価ボードのレイアウト、
メーカーのアプリケーションノート、規格。

調べた結果は、まずその基板の配置表と `finish.py` のコメントに根拠として書く。
他の基板でも使える知見なら、ここに 1 ファイル足し、上の表に 1 行足す。
1 ファイルの形は次のとおり。

```
# <回路の種類>

何が効くか (1〜2 文)。元の基板とその見本の場所。

## 配置
部品をどの順に、どこへ置くか。理由とともに。

## 配線
固定配線にするもの、ベタにするもの、禁止領域。finish.py のどの名前で書くか。

## 確かめ方
DRC で見えないものを何で見るか。

## 出典
データシート、アプリケーションノート、規格。
```

書くのは**この手順で実際に試して確かめたこと**と、出典のある数値だけにする。
未検証のことは「未検証」と明記する。
