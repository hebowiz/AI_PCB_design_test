# 微小電流・高インピーダンス

nA 以下を測るとき効くのは、センサノードに流れ込む余計な電流。アンプの入力
バイアス電流と、基板表面や部品のリーク。高インピーダンスのノードは短く、
他のネットから離す。

元の基板はドーナツ電極の微小電流計 (90 x 115 mm、2 層、CR2032、BLE)。
電極の電流を 10 MΩ のシャントで電圧にし、OPA333 で 10.1 倍して ADC に入れる。
端子入力の派生版 (1 MΩ、7.2 倍、90 x 34 mm) もある。設定の見本は
`examples/electrode-2layer/finish.py`。

## 部品の選び方

- **入力バイアス電流は測定電流にそのまま足される**。OPA333 は 70 pA なので、1 nA を
  測ると 7 %。電極を外した状態の読みを定数として引けば消せる。オフセット電圧の
  ほうはシャントで割ると無視できる (10 µV / 10 MΩ = 1 fA)
- **単電源アンプの出力は負レールまで振れない**。OPA333 は最悪 50 mV 残る。
  これが測定の下限になる (端子版で 50 mV / 7.2 MΩ = 6.9 nA)。ゲインを上げても
  比率は変わらない。0 付近まで測るなら、シャントの下端を基準電位に持ち上げる
- ADC の手前に RC の帯域制限 (1 kΩ + 100 nF で約 1.6 kHz)

## 配置

- 入力 (電極または端子)、シャント、アンプの入力を 1 か所に固め、センサノードを最短にする
- センサノードの近くに、電源やデジタル (無線モジュール) の配線を通さない
- 無線モジュールは基板の端に置き、アンテナを外へ向ける。アンテナの下と周りは
  表裏とも銅を置かない (→ 禁止領域)

## 配線

| 何を | どう書くか (`finish.py`) |
| --- | --- |
| アンテナ下 | 残し続ける禁止領域。モジュールの外形のうちパッドの無い側を囲む (`pre_hook` で形から求める見本あり) |
| 露出電極 | 配線後にゾーンとして足す (`post_hook`)。atopile はフットプリントを書き直してカスタムパッドを消すので、フットプリントには置けない。円ゾーン + 中を抜くルールエリア + レジストの円環開口。表裏はステッチングビアで繋ぐ |
| 電極と基板端 | 露出銅は穴の縁から 0.5 mm 手前まで。業者の銅と基板端の下限 (0.2 mm) に余裕を持たせた値 |
| GND ベタ | 電極が表を占める基板では、電極の外の帯の裏面だけ (端子版は両面) |

表面処理は ENIG にする。HASL は露出電極が凸凹になり酸化しやすい (`references/fab/README.md`)。

## 確かめ方

- センサノード (電極 ~ シャント ~ アンプ入力) の長さと、隣を通るネットを画像で見る
- アンテナの下に銅 (ベタ、配線、ビア) が無いかを表裏で見る
- `scripts/netlist_diagram.py` の表で、センサノードに意図しない部品が付いていないか

## 未検証

- **ガードリングは入れていない**。10 MΩ のノードは基板表面のリークを拾う。
  さらに低い電流を狙うなら、センサノードと同電位で駆動したガードで囲む。
  この手順では試していない
- アンテナの向きはモジュールのパッドの無い側から判断した。データシートの図との
  突き合わせはしていない
