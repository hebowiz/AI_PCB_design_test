# スイッチング電源

効くのは、高い di/dt が流れるループの面積と、dv/dt の大きいノードの面積。
どちらもルータに任せると広がる。パワー段は配置とベタと固定配線で全部決め、
ルータには制御・計測側の信号だけを引かせる。

元の基板は降圧 DC-DC (80 x 60 mm、4 層、内層 2 枚を GND 面、20 V → 15 V、5 A)。
設定の見本は `examples/dcdc-4layer/finish.py`。以下は降圧 (ハイサイド N-MOSFET +
ダイオード) の場合で、同期整流や昇圧でも考え方は同じ (ループの部品が入れ替わる)。

## 配置

**ホットループを最小にする**。降圧なら入力コンデンサ → ハイサイド FET → ダイオード
(または ローサイド FET) → 入力コンデンサの GND。電流が断続するのはこのループ。

- FET とダイオードを横に並べ、FET のドレイン (VIN) とダイオードのアノード (GND) を
  同じ側で隣り合わせる
- 入力のセラミック (10 µF ×2 + 100 nF) を、その 2 つのパッドの真上でまたがせる。
  バルクの電解はループの外でよい
- 4 層なら直下 (約 0.2 mm) の In1 を途切れない GND 面にする。ループの面積が
  外形程度になり、帰路が面の上に閉じる
- ループの GND 側は、パッドの脇にビアを数本固定で打って面に落とす (`VIAS`)

**SW ノードは最小面積**。FET のソース → ダイオードのカソード → インダクタの帯だけ。
dv/dt の大きい銅はアンテナになる。スナバ (例: 2.2 Ω + 1 nF) はダイオードの直近。

**制御・計測は離す**。制御 IC、アンプ、コネクタは基板の反対側の半分に寄せ、
パワー段とは GND 面で隔てる。インダクタの下と SW の横を信号に並走させない
(→ 配線中だけの禁止領域)。

## 配線

| 何を | どう書くか (`finish.py`) |
| --- | --- |
| VIN / SW / インダクタ出力 / VOUT | F.Cu のベタ (`ZONES`)。配線中は同じ輪郭の禁止領域が自動で重なり、ルータが入らない |
| ゲート | 固定配線 (`TRACKS`)。ゲートピンが SW の帯の中にあるなら、真下のビアで B.Cu に落とし、帯の下をくぐってドライバの直上で上がる。ゲートループは経路の長さ x 板厚 |
| ターンオン / ターンオフ抵抗 | 分けて置く (例: 4.7 Ω / 1 Ω)。どちらもドライバと FET の間に |
| ドライバの TS (ソース参照) | ドライバから SW の帯へ最短の固定配線 |
| ブートストラップ | ドライバ → C → ダイオードを固定配線で最短に |
| 電流検出 | ケルビン接続。シャントのパッドの内側の縁から 2 本を並走させ、アンプ直前のフィルタ抵抗まで。2 本の間とその周りを配線中の禁止領域 (`ROUTE_KEEPOUTS`) にして他の信号を割り込ませない |
| 電圧の検出点 | FB とモニタは VOUT のベタから 0 Ω 1 本で取り出し、検出点を 1 点に固定する。VIN 側も同じ |
| GND | 表面実装の GND パッドをすべて直近のビアで内層に落とす (`FANOUT`)。配線後に表裏を GND ベタにし、約 3 mm 間隔のビアで縫う (`POURS`, `STITCH`) |

ベタの座標は配置表と一緒に直す。**パッケージを変えるとパッドがベタの縁から外れ、
DRC は未接続にするがルータは引けない** (`references/fab/README.md`)。

## 確かめ方

- 3D レンダと F.Cu の画像で、ホットループの 3 部品が外形程度にまとまっているかを見る
- SW の銅の面積が、FET・ダイオード・インダクタのパッドを繋ぐ分だけになっているか
- ケルビン線の 2 本の間に他のネットが入っていないか (DRC は見ない)
- ゲートの経路が SW の帯の外へ大回りしていないか
