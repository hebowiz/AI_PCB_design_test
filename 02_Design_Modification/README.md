# B-2 — 既存KiCad設計の部分変更（手段2のみ）

人間が作成した回路図・PCBをAIに渡して、明示的に指定した部分のみ変更させる。

- `original/` — 原本を保存（変更禁止）
- `working/` — 原本のコピーを修正
- `reports/` — 差分、検証結果、レビューを保存

実際の試験時に各サブフォルダを作る。対象基板はまだ未配置。

**注意:** `$pcb-pipeline` は新規レイアウトの再生成を含むため、既存設計にそのまま適用してはいけない。保護対象と差分確認の仕組みを用意する。

BはKiCad単独の手段2だけで実施する。atopileやEasyEDAによる既存設計修正は今回の対象外。
