## R-0002：Y1と負荷容量の再選定

Y1を`ABM8-12.000MHZ-B2-T`から`ABM8-12.000MHZ-12-B1U-T`へ変更した。12MHz、基本波、3225・4端子の外形とピン接続を維持し、CLを18pFから12pFへ変更した。新しい品種の初期許容差は±10ppm、温度安定度は±10ppm（−20〜+70°C）。初年度エージング±2ppmを加えた単純和は±22ppmで、FT232Hの±30ppmに対して残り8ppmを負荷誤差などの予算とする。[Abracon ABM8、2020-07-29改訂](https://abracon.com/Resonators/abm8.pdf)、[FT232H v2.2 §6.3](https://www.mouser.com/datasheet/2/163/DS_FT232H-3555343.pdf)

C13/C14を27pFから15pF・±1%・C0G・50Vの`GRM1555C1H150FA01D`へ変更した。0402のフットプリントは維持した。CL = 15×15/(15+15) + 4.5 = 12pF。4.5pFは従来からの寄生容量仮定であり、測定値ではない。[村田製作所 Reference Sheet、2017-02-09、p.1（公開ミラー）](https://www.icbanq.com/icdownload/V2_DATA/ICBShop/Board/Murata/GRM1555C1H150FA01-01.pdf)

FTDIがこのAbracon型番を指定しているわけではない。±22ppmの合算だけでは発振回路全体の±30ppmを保証できない。実装後に負荷容量の調整、温度範囲での周波数、起動余裕、駆動レベルを確認する必要がある。ABM8の12MHz帯はESR最大120Ω、駆動レベル最大100µWで、FT232Hとの発振余裕は実測していない。1年を超えるエージングも今回の予算には含めていない。

選定時には同じTDK系列の15pF・1%品も調べたが、メーカー表示がNRNDだったため採用しなかった。採用品の調達時には最新の承認図・供給状況を再確認する。発注はしていない。

## R-0004：固定3.3V LDOの削除

U3（AP2112K-3.3）を削除し、U1.40 VREGINの給電先を+3V3からUSB5Vへ変更した。U1.39 VCCDは+3V3へ接続したまま、内蔵レギュレータの出力として使用する。VREGINとVCCDの直接接続を分離し、+3V3の他の端子は維持した。可変VIO用U4はそのまま残している。[FT232H v2.2 §6.1、p.45](https://www.mouser.com/datasheet/2/163/DS_FT232H-3555343.pdf)

FTDIのUM232H v1.4では、表6に3.3Vレギュレータ出力電流100mA maxがあり、§7.1では内蔵レギュレータでVCCIO/VPLL/VPHYと外部ロジックを給電する構成を説明している。これは外部へ追加で100mAを取り出せるという意味ではない。[UM232H v1.4、p.15–16（FTDI文書の公開ミラー）](https://www.mouser.com/datasheet/3/35/1/DS_UM232H.pdf)

周辺負荷は次の条件で概算した。これは設計判断のための予算で、全条件での最大値保証ではない。

| +3V3負荷 | 計算・予算 |
| --- | --- |
| EEPROM U5 | 書込みを2mA枠で計上。DS21794Gの2mA maxは5.5V・3MHz条件であり、3.3Vでの測定値ではない |
| TX/RX LED | 両方点灯で約0.56mA |
| R2/R3/R5/R6 | 4本すべてに3.3Vが掛かる保守的な計算で1.32mA。実際には同時成立しない状態を含む |
| U2 VCCA | 静止13µA max（−40〜85°C）。動的電流は3MHz、2方向各2本でCpdA=2.3/20.1pFを使い約0.444mA。A出力2本を各15pFと仮定し約0.297mAを追加 |
| R4競合時 | 3.3V/2.2kΩ=1.5mAを一時的な追加枠として計上 |
| 合計 | 上記約6.14mAに対し、周辺回路の計画枠を8mAとした |

U2のCpd値は25°C・等電源3.3Vの典型値を使った見積りで、VIO=1.8/2.5Vや実配線容量を含む保証値ではない。[TI SN74AXC4T245 Rev.B、表5.5・5.14](https://www.ti.com/lit/ds/symlink/sn74axc4t245.pdf)。EEPROMの条件は[Microchip DS21794G、表1-1](https://ww1.microchip.com/downloads/en/DeviceDoc/21794G.pdf)による。

FT232Hの54mA typと外部負荷枠8mAを合わせると約62mAで、100mAとの差は約38mAとなる。ただし54mAは最大消費電流ではなく、この差を保証された余裕とは扱わない。ヘッダのVIO/5V負荷はU4/U6経由でUSB5Vから供給され、VCCDの追加負荷には入らない。資料に沿う構成と今回の小さな周辺負荷からU3削除案を採用したが、6Mbps通信・EEPROM書込み・全温度・起動・サスペンド復帰時の電圧と温度上昇の確認は残る。FT232H全体の最大電流保証がないため、実測で不足した場合は外付けレギュレータ方式を再検討する。

C1の1µFとC2の2.2µFは、それぞれUSB5V入力とVCCD出力の容量として残した。将来のPCB更新ではU1の該当ピン付近へ配置し、DCバイアス下の容量と過渡応答を確認する。

既存ライブラリは変更していない。U1.39の汎用シンボルが`power_in`であるため、+3V3にPWR_FLAGを追加し、この5V入力構成ではVCCDが電源源になることを図面へ明記した。ERCの駆動宣言であり、レギュレータの電流容量や実動作を検証するものではない。

## R-0005・R-0006

R-0005の「USB設定後」は、ホストがUSB列挙の過程で非ゼロのSET_CONFIGURATIONを送り、使用する構成を選んだ状態を指す。COMポートを開く操作やEEPROMへ設定を書き込む操作とは時点が異なる。FT232HのPWREN#はUSBで設定された後にLow、サスペンド中はHighとなる。現回路はLowでQ1がOFF、PWR_ENがHighとなりU6/U4を有効化する。[FT232H v2.2 表3.5](https://www.mouser.com/datasheet/2/163/DS_FT232H-3555343.pdf)

この動作には、EEPROMでACBUS8をPWREN#へ割り当てる設定が別途必要。空のEEPROMの既定状態を、設定済みとして扱わない。SW2は手動の出力切断を担う。U6/Q1/SW2関連の部品・接続は変更せず、修正は保留とする。再開にはユーザーの指示が必要。

R-0006はユーザーが「OK。修正は不要。」と判定。別途回答の`20261122-1805`を2026-11-22 18:05 JSTとして記録する。R4=2.2kΩを含め、EEPROM回路の部品と接続は変更していない。
