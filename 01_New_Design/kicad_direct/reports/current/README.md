## 変更と判断

C13の位置を維持し、C14を信号パッドが水晶へ向く方向へ回転・移動した。両容量の信号パッド中心間距離を1.815mm、中心線経路を1.949mmに揃えた。水晶パッドを接続の合流点とし、IC側は45°で短く引き出した。幾何学的な一致であり、寄生容量の一致や発振余裕は未測定。

GNDビアを4個追加・3個移動し、総数は29→33個。D1とC14は近くのGNDビアを共用し、C9は0.85mmの直線で専用ビアへ接続した。D1/C9はゾーンだけでは帰路を確保できなかったため短い配線を残す。Y1/C13/C14はサーマルと近接ビアを使う。C13下と右側の不要な細いベタを1個の切り抜きで除去した。Y1直下の追加削除は行っていない。

表面GNDの最小幅・スポークを0.2mmへ変更したところ、C22周辺とU1の9〜11ピン周辺のGNDが分離した。ビアで裏面へ接続し、C22/R8のサーマル角度を調整した。U1側のビア用空間を確保するため、VPLLのC10手前の一部配線だけを0.15mmずらした。J2は不足するサーマル接続を短い0.2mm幅の下向きGND配線で補った。裏面ゾーンの最小幅0.1mm・スポーク0.15mmと、既存の4個のルール領域は維持した。

## 残る評価
