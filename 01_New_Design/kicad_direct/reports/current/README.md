## R-0036：鋭角と分岐の定義

ユーザーの「銅箔輪郭の内角90°未満」と、銅箔に入り込む空隙の鋭角を区別した。今回の条件では銅箔側の凸内角90°未満は0候補。一方、銅箔内角270°超、すなわち空隙側が90°未満の切込みは保存済みベタ込みで205候補だった。これを「銅箔内角90°未満が205件」とは扱わない。配線・パッド・ビアだけの集合では77候補で、保存ベタとの合成によって輪郭が変わる。

輪郭は3µmで簡略化し、隣接辺20µm以上、角度差0.1°を条件にした。円弧近似・小さな輪郭を含む全形状の厳密証明ではない。修正時は両方の鋭い形状を確認する案とする。

代表例はF.CuのC4.1近傍+3V3、(105.681,118.825)mm。空隙45°、銅箔側315°の切込みがある。F.Cuの(103.575,110.798)mmにも約49.1°の空隙がある。details.pngの最上段を参照。

中心線の途中分岐は27箇所、パッド・ビア内の分岐は別に6箇所。+3V3の(106.800,126.600)mm、(107.850,121.100)mm等を確認した。USBのESD分岐2箇所とXTAL_OUTの負荷容量分岐も候補に含まれるため、信号経路を悪化させてまで一律に移動しない。分岐27箇所の座標・ネット・UUIDはmetrics.jsonに保存した。

## R-0037：短い45°区間と実質直角

今回の抽出条件は、端子・ビア・分岐を挟まない同方向の45°曲がり2回で、中間線分長が`max(0.5mm, 配線幅×2)`以下となるもの。これは調査用の提案基準であり、ユーザーが承認した数値規則ではない。長さだけを0.25/0.5/1.0mmとした感度確認では51/80/135候補となる。

U2.4のFT_TXDは、(109.000,128.675)→(109.100,128.575)mmの0.141421mm区間、配線幅0.15mm。画像でも短い面取りを挟むL字として確認できる。+3V3のC16/U2付近やR6付近にも類例がある。原因は、単独の90°頂点を除く検査と、連続区間全体の形状評価が別であったこと。現行の単点90°検査が0件でも今回の要求への適合を意味しない。

86候補は226本の既存線分に関係し、途中分岐候補と合わせると275本に及ぶ。これは撤去計画ではなく調査対象の広がりで、全面再配線の承認でもない。端子短辺中央の引き出しを保ち、周辺の対角区間を延ばす形で局所的に整理する。

## R-0039：GNDの細線・半島

保存済みゾーンに半径0.5mmの収縮・拡張を行い、幅1mmの領域として残らない部分を抽出した。境界誤差10µm、残差面積0.02mm²以上を候補とする。丸い角やサーマルも含むため、251領域をそのまま違反とはしない。203領域は候補内に直接のGND端子・ビアがなく、157領域は太い領域との接点が一まとまりとなる半島候補。接点は開操作に基づくもので、電気的な端点数ではない。

代表例：

- F.Cu、R5付近(118.200,126.800)mmの水平断面幅は0.179001mm。候補領域は約2.853mm²。直接のGND端子・ビアを持たず、画像でも細長い領域が見える。
- B.Cu、基板左側(101.650,118.901)mmの水平断面幅は0.649mm。候補領域は約6.933mm²。長い配線に挟まれたGNDの細い領域が見える。

この断面幅はその座標での測定値であり、領域全体の最小有効幅ではない。GND銅箔全体で端子・ビアを一切含まない独立島は今回0個だったが、端子につながる本体から伸びる半島・ひげの不存在を意味しない。

表裏のGNDゾーンはサーマル幅0.15mm・ギャップ0.15mmで設定されている。R-0023のサーマル要求と1mm基準を両立させるため、端子直近のサーマルを例外候補として明示し、長い細線・不要な半島とは区別する案を提示する。狭ピッチ部の全接続を1mmへ広げる案は採らない。例外はまだ承認されていない。

## 修正計画と保護範囲

1. 上記の判定条件とサーマル例外案をレビューし、修正範囲の承認を得る。
2. U2周辺・R5/R6周辺の短い45°区間、明確な途中分岐、3組のビア候補から局所修正する。端子引き出し、USB5V幅、ビア寸法・離隔を保持する。
3. 信号経路が落ち着いてからGNDを再フィルし、不要な細線の除去、必要領域の幅確保・GNDビア追加を選ぶ。USB・水晶直下のGNDを削らず、各候補の用途を確認する。
4. その後、残る候補を基板全体で再評価する。30ネット・275線分に関係するため、1箇所だけの修正では終わらない可能性が高い。部品移動は現時点で計画せず、必要なら理由と範囲を提示する。
5. ERC・DRC・未配線・回路図整合性、今回の指標、既存のUSB/水晶・電源順序・パッド引き出しを同一条件で確認する。修正前画像はこの成果物コミットから取得し、修正後は同じ画角のcomparison.pngへ集約する。

回路接続・部品定数・基板外形・J1/J2/J3・スイッチ位置・板厚・層数を保護する。検証除外追加で合格扱いにせず、GNDの一括削除・全面再配線はしない。
