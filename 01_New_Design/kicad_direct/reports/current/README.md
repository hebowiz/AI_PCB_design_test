## 今回の変更

- UART 4信号を一緒に引き直し、U1/U2の短辺中央から引き出した。群全体では短縮したが、FT_TXDは20.253→25.953mmへ延長した。隣接経路と長い45°区間を確保した結果であり、全ネット短縮とは扱わない。
- VIOの閉ループ・重複をなくし、U4.5→C19.1→C17.1→U2.16の順序へ変更した。R11を(115.5,129.0)/90°から(116.2,129.6)/0°へ移動し、PWREN/PWR_ENも通路を組み替えた。
- C18を(101.1,130.4)から(101.1,129.03)へ移し、USB5V→C18→U4.1を直列の配線経路として表現した。コンデンサの電気接続は従来どおり電源–GND間。
- R14/R15を90°から−90°へ回転し、LEDアノードへの配線を直線化した。電源分岐はC3端子・抵抗端子へ寄せた。その他、REF12Kと複数の端子間経路を再構成した。
- GNDはサーマル・反対層の帰路を保護し、13箇所、計2.8903mm²を除去した。UART変更後の帰路補強としてGNDビアを2個追加した。

## 検証

## 残る課題

分類は要修正345件、未承認例外110件、誤検出21件。独立欠陥数ではなく重複を含む。要修正は疑似直角45・途中分岐11・GND形状193・鋭い空隙96。**候補数の減少を完了判定に使わない。** 残る78個の非GNDビアについても全数の必要性は立証できていない。

EEPROM群は配線順序とR4移動を変えて試したが、残り端子の通路閉塞、EE_DO/EE_CLKの短絡、実装外形干渉が生じたため採用しなかった。帰還抵抗・FT232H電源・EEPROM周辺は、隣接する電源配線と部品の位置関係を合わせて見直す必要がある。GND幹線は特に裏面左側に細い経路が残る。必要な帰路を削るだけでは直せず、信号通路の再割付または部品群の移動が必要。今回、その成立案まで作れなかった。

GNDを広く削った候補はDRCに合格しても新しい鋭い切込みが増えたため取り下げた。13箇所へ絞った候補でも1mm以上の全方向最小幅を保証するものではない。サーマル開口などの例外案は未承認。検査閾値や例外を完成済みスキルに昇格していない。
