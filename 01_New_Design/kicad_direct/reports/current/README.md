# A-2 配線品質の再調査と再配線計画

対象はR-0036〜R-0040。基準成果物は`0d7a11603da2097970062df54214a574c1589c77`、PCBは`d1d9cf5f6db50c702c2ec3cb23fa6afa74411902`。今回は分類・計画のみで、CADを変更していない。

局所的な線分修正だけでは要求を満たせない。端子間の経路と機能ブロックの配置を見直す計画へ変更する。完了条件は「未解決の要修正箇所0件」とし、未承認の例外を残したまま完了にしない。

要修正389件は対応管理上の件数で、同じ銅箔を複数の検査が捉えた重複を含む。画像と測定だけでは例外を立証できない箇所も要修正計画へ残した。389個の独立した欠陥が確定したという意味ではない。例外案118件はユーザー未承認であり、検証除外に追加していない。

途中分岐の誤検出7件はB006/B007/B008/B013/B016/B022/B027。中心線の微小余長で次数が増えるが、半径0.05mmと0.10mmの断面では二方向のみで、銅箔画像でも独立した枝がない。余長自体はネットの再配線時に整理する。USBのESD接続B018/B019とGND帰路B021は、機能上必要な分岐として保持を提案する。

GNDの誤検出18件は、太い面の境界を開操作で丸めた残差である。幅不足のネックと取り違えない。サーマル候補は端子近傍というだけでは除外せず、G001のような行き止まりとG030/G182の突出を要修正へ戻した。合理的な例外9件はJ1シェルの局所サーマルで、広いGND面に接続する形状を確認した。

## 鋭い切込みとGND帰路

凸鋭角0件を合格条件にする方法を改め、保存済み銅箔の空隙側の角も対象にした。203候補のうち97件を要修正とし、106件は通常のサーマル開口端に限定した例外案である。後者はGNDパッドから約0.15mmで既存ギャップに対応し、明示配線の途中分岐から離れている。画像でもサーマル接合部と確認した。ユーザーが開口角にも例外を認めない場合は、スポーク角・幅・周囲銅箔を調整して鈍角化し、サーマル機能を維持する。

GNDの要修正項目ごとに`ground_action`を記録した。不要な領域は切除、必要な帰路は拡幅を優先し、拡幅困難な箇所だけGNDビアで補強する。反対面信号との重なり、GND配線・端子・ビア接触も列記した。候補内に直接端子がないことを削除理由にはしない。

G158/G219の左側裏面などは、ビア補強済みでも1mm未満の幹線が残る。追加ビアだけで幅要求を満たしたとは扱わず、周辺信号の通路を内側へ移して幅を確保する案を優先する。R5付近G083は既存GND配線との接触を保護し、信号・電源通路の再配置で帰路を広げる。

座標枠は調査対象の概略範囲であり、移動先の確定座標ではない。部品を移さず再配線できれば移動しない。固定すると再び不自然な曲がりやGND分断を生む場合は、表の周辺部品について位置・向きの固定を緩める必要がある。未試行の移動量や配置成立を保証しない。

常に保護するのは回路のネット・部品値・型番・フットプリント、22×50mm外形、1.6mm厚・2層、J1/J2/J3とSW1/SW2/SW3の機構位置、既存のビア離隔・パッド引出し・電源幅・レジスト・サーマル条件である。U1の位置も今回の提案では維持する。USB/水晶については、電気的条件と直下GNDを維持しつつ、線分UUID・経路の完全一致という保護は緩める案とする。

推奨順は、A/Bの優先経路とD/Eの部品配置を先に同時検討し、USB・水晶、電源、UART、その他制御を配線する。最後にFのGNDを整え、全項目を再検査する。領域間の依存を確認せず、一件ずつ面取りして既存経路へ押し込む方法は採らない。
