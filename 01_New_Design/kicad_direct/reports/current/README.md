# A-2 PCB配線スタイルの修正候補（未達項目あり）

対象はR-0036〜R-0040。ブランチは`codex/a2-pcb-style-refinement`、CADコミットは`d1d9cf5f6db50c702c2ec3cb23fa6afa74411902`。比較元は調査コミット`0afd6a69659793ee144c9bd6ff7d2882ef4d1e8a`で、CADは承認済み`ca191ab2a900714d53f7ab0eb8984b58f3af7ef8`と同一だった。

局所修正と検証を行った。R-0036・R-0037・R-0039には未達箇所が残るため、全件解消とは扱わない。人間の最終判定は未実施。固定Workspaceは更新していない。

## 採用した経路とGND処理

PWREN_Nの(118.700,127.700)/(118.750,125.250)mm、PWR_ENの(112.050,127.150)/(113.150,126.050)mm、RESET_Nの(115.500,121.400)/(114.350,121.150)mmの各ビア対を除いた。経路は表面に接続し直し、既存の部品位置と端子ネットを保持した。

U2.4のFT_TXDは短辺中央の直線引き出しを残し、縦配線をx=109.7mmへ寄せて、0.141mmの面取りを約0.884mmの対角区間へ変更した。単にパッド近くの曲がりを削る方法では、短辺中央からの引き出しが崩れるため採用しなかった。

左端のGND細線部には、(101.650,116.300)mmと(101.650,119.300)mmへドリル0.3mm・径0.6mmのビアを追加した。表面EE_CSの縦配線をx=101.65mmからx=101.1mmへ移して離隔を確保し、裏面の細い領域を表面GNDへ接続した。この追加はGND帰路の補強であり、単なる配線都合による信号ビアの追加ではない。幅1mm未満の領域自体は残るので、例外の妥当性は人間レビュー対象とする。

GND切欠きは、端子・GND配線・ビアとUSB／水晶の反対面参照領域を保護して選んだ。既存2個のGNDゾーンの輪郭を変更し、既存4個のルールエリアは変更していない。線分・切欠きの座標とUUIDは`preservation.json`と`metrics.json`に保存した。

R5近傍の細い候補には、既存GND配線`da0d8af8-298e-428c-842a-4768a06692f9`、(118.2,127.15)→(118.2,124.65)mmが接触する。単に「候補内に端子・ビアがない」ことだけでは不要な半島と判定できない。除去案はこの帰路と干渉し、近傍のビア追加案も離隔を満たさなかったため、今回は保持した。

## 検証と保護

ERC、DRC、未配線、回路図不一致はいずれも0件。既存の無視チェックはERC4項目・DRC5項目で、追加・変更していない。58部品の位置・角度・属性、全パッドの番号・ネット・形状・位置を照合した。ICの短辺中央引き出しと45°単位の線分も検査に合格した。

USB・水晶の全配線とビアは変更していない。両面の該当信号直下について、2µmの境界許容を超える新たなGND参照面の損失は検出しなかった。22×50mmの外形、板厚1.6mm、2層、部品位置、設計ルール、回路図、ライブラリ、製造データを保持した。PCB内では既存72配線・ビアを除き、65配線・ビアを追加している。元のUUIDを持つ残存配線・ビアの属性変更はない。

既存の配線グラフ検査も前後比較した。独立ループ候補2、重複線分候補2、迂回候補143は前後同数。非GND行き止まり候補は19→17で、全候補を実不良と確定した数ではない。電源順序の機械検査は10経路中8経路を確認し、C18とC19を含む2経路は前後とも最短経路上に対象パッドを拾わなかった。この検査だけで2経路の配置順序を合格とは扱わず、過去のユーザー判定も変更しない。

USB5V系統の0.25mmネックダウンは既存の2線分・合計1.18721mmを保持し、その他は0.5mm以上。電気特性、EMC、GND帰路のインピーダンス、製造性の実測は未実施。

## 試行と作業時間

2026-11-26 21:42 JSTに着手し、22:18 JSTにCAD候補をコミットした（36分）。成果物・議事録の作成時間はmanifestに記録する。

最初の面取り拡張では、パッド間への銅箔侵入、C23のサーマル不足、切込みの増加を検出し、該当案を戻した。パッド・ビア近傍の形状を保護し、切込みを増やさない条件で再選別した。U1.37の側面引き出しとQ1付近の同一ネット近接も最終検査で見つかり、当該形状を元へ戻した。C4の引き出し変更案は周辺離隔を満たさず不採用とした。

一時PCBの別名にプロジェクト設定が対応していない試行では、GND再フィルの結果が変わった。対応する既存設定を読み込んで再実行した。GNDの切欠きは単純な穴追加ではゾーン外周との交差を正しく扱えず、輪郭の差集合へ変更して再検証した。Pythonの補助ファイル名と標準モジュールの衝突、およびSWIGの削除済みオブジェクト参照も修正した。これらの失敗出力は最終成果物に混ぜていない。

試行CAD・ログ・使い捨てコードはGit管理外に置き、再利用する読み取り専用ツールはmainの`tools/design_review/`へ集約した。今回の候補検査を承認済み設計スキルへ昇格していない。
