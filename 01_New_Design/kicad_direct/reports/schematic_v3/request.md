# A-2 回路図視認性改善 V3 — 電源・GND表現と設計意図の可視化

## 目的

A-2回路図のV2成果物をベースに、人間の回路設計者が接続関係・電源構成・基板設計上の意図を理解しやすい回路図へ改善してください。

今回はユーザーによる具体的な改善要望6項目を反映します。

V2で実現した「機能ブロックごとの配置」「関連部品間の実線接続」「信号経路を目で追えること」という特徴は維持してください。

**目的は回路図の表現品質を改善することであり、電気回路そのものを変更することではありません。**

## 2. 改善要望

### 2.1 GND接続の表現

GNDネットの配線は極力短くし、部品のGNDピン近傍に下向き三角形（▽）のGNDシンボルを配置してください。

基本方針：

- 長距離にわたるGND配線を避ける。
- GNDシンボルは接続対象の部品ピンに近接配置する。
- 同一機能ブロック内で近接するGNDピン同士は、実線でまとめてからGNDシンボルへ接続してよい。
- GND接続で図面が煩雑にならないようにする。
- 異なるネットを意図せず統合しない。

▽は単なる装飾ではなく、KiCad上で正しくGNDネットに接続される電気的なシンボルとしてください。

### 2.2 関連する2本の信号の並走

関連する2本の信号は、対になっていることが視覚的に分かるように、可能な限り平行・近接して描いてください。

対象例：

- USB D+ / D−
- XTAL_IN / XTAL_OUT

基本方針：

- 2本の間隔は、シンボルの隣接ピン間隔と同程度を目安とする。
- 可能な範囲で並走区間を長くする。
- 2本の経路や屈曲の仕方を揃える。
- 不必要な交差や大きな間隔の変動を避ける。
- 部品の配置関係で困難な場合は、無理な並走より読みやすさを優先する。

水晶の2信号とUSB差動信号は電気的性質が異なるため、回路図上の並走表現をPCB上の同一配線制約と混同しないでください。

PCBの差動インピーダンス・配線長などの変更は今回の対象外です。

### 2.3 電源ネットのシンボル表現

各種電源ネットには、**円を水平線が貫通する図柄（○に横棒）**の電源シンボルを使用してください。

目的は、そのネットが電源系であることを明確に示すことです。

基本方針：

- USB5V、+3V3、VIOなど、実際の電源ネットに適用する。
- シンボル付近で電源ネット名を識別できること。
- 同じ電源ネットには統一した表現を使う。
- 電源入力、生成電源、スイッチ後電源の違いが分かるようにする。
- 必要以上にシンボルを乱立させない。

まずKiCad標準ライブラリに適切なシンボルがあるか確認してください。

適切なものがない場合は、プロジェクトローカルのカスタム電源シンボルを作成して構いません。

カスタムシンボルを作る場合も、KiCadの電気的接続、ネット名、ERCを正常に扱える構造にしてください。

`PWR_FLAG`は電源シンボルの代用品として使用しないでください。

### 2.4 バイパスコンデンサ等の配置表現

ICの電源入力ピンや電源出力ピンの近傍に配置すべきバイパスコンデンサ・デカップリングコンデンサは、回路図上でも対象ピンの近くに配置してください。

特に電源入力の場合、電源の流れに沿って、

**電源供給元 → コンデンサ接続位置 → IC電源入力ピン**

という位置関係を基本としてください。

ただし、コンデンサ自体は電源とGNDの間に並列接続されるものであり、電源経路に直列挿入してはいけません。

目的は、実際の基板上でコンデンサをICピン近傍に配置すべきという設計意図を図面でも表現することです。

対象の例：

- FT232Hの電源ピン周辺
- UARTレベル変換ICの電源ピン周辺
- LDOの入力・出力コンデンサ
- EEPROMの電源コンデンサ
- 電源スイッチICの周辺コンデンサ

コンデンサを単独で並べるだけでなく、対応するIC・電源ネットとの関係を意識してください。

### 2.5 ICの複数電源・GNDピンのまとめ接続

ICの複数ピンが同一のGNDネットまたは電源ネットに接続されている場合、ICシンボルの近傍でそれらをまとめて実線接続して構いません。

基本方針：

- 同一ネットのピンのみを接続する。
- IC付近の短い配線でまとめる。
- まとめた先に電源・GNDシンボルを配置する。
- 不自然な長配線や複雑な交差を増やさない。
- ピン名・ピン番号の視認性を損なわない。

FT232Hのような多ピンICでは、既存シンボルのピン配置によっては無理なまとめ接続を避け、個別の電源・GNDシンボルを使って構いません。

### 2.6 電源生成の流れを可視化

電源生成回路は、供給元から二次電源へ展開する**シリーズ・ツリー構造**として配置してください。

基本方針：

- 左側に大元の電源入力を置く。
- 右方向へ二次的に生成される電源を展開する。
- 電源スイッチによる入力・出力の関係を明確にする。
- 各電源生成ICの入力・出力コンデンサを適切な位置に配置する。
- 電源ネットの名前と供給元を対応付ける。
- 電源生成回路全体を一つの機能ブロックとしてまとめてもよい。

今回の回路ではUSB5Vから固定3.3V、可変VIO、スイッチ後の電源などが存在します。

ただし、電源の分岐関係や生成順序は、必ず既存ネットリストと回路構成に基づいて確認してください。

回路図を美しくするために実際とは異なる電源系統を描いてはいけません。

## 3. V2の良い点を維持する

以下の内容はV2で一定の成果が得られているため、できる限り維持してください。

- 機能ブロック単位の整理
- ブロック内部の実線接続
- USBからUARTへの信号経路の可視化
- LDOの帰還・電圧切替回路の可視化
- EEPROMやLED周辺の局所接続
- 単一シートでの全体把握

なお、V2に対するユーザー評価では、USB信号線の迂回は許容されており、UART信号線の非接続クロスも読みやすいと評価されています。

したがって、**USB配線の迂回やUARTのクロスを一律に禁止したり、必須修正項目として扱ったりしないでください。**

今回の指示と矛盾しない限り、V2の良い表現は残してください。

## 4. 電気的接続と部品情報の保護

今回の変更は回路図の見た目と表現方法に限定します。

既存の実回路について、以下は変更禁止です。

- 部品の追加・削除
- 既存部品の番号・定数・型番
- フットプリント
- ピン定義・ピン機能
- 電気的ネット接続
- 回路構成・電源系統
- PCB・製造データ

電源・GNDシンボルについては新規追加を許可しますが、回路に新しい機能部品を追加することは禁止です。

**電源シンボル追加後の検証方法に注意してください。**

KiCadでは電源シンボルの追加によって、XMLネットリストに表れるシンボルインスタンスやライブラリ情報が変わる場合があります。

したがって、V2以前とXML全体が完全一致することだけを合格条件にはせず、少なくとも以下を確認してください。

- 既存の実部品がすべて維持されていること。
- 各実部品の全端子について、接続先ネットが修正前後で一致すること。
- 既存ネットの意図しない統合・分離がないこと。
- GNDシンボル・電源シンボル追加に起因する誤接続がないこと。
- 電源シンボル等を除いた既存部品の属性・UUID・端子識別子が維持されていること。
- ERCで新たな違反が発生していないこと。

電源シンボルの外観変更と電気的接続の保護を両立させてください。

## 5. 画像確認と改善

回路図の改修後、KiCadでPDF・PNGを出力してください。

図面全体に加え、少なくとも以下を拡大して確認してください。

1. USB・ESD・FT232H周辺
2. 水晶・発振回路
3. UARTレベル変換ICと外部端子
4. 電源生成回路全体
5. LDO入力・出力と帰還回路
6. 電源・GNDシンボルの代表的な使用箇所

次の観点で自己レビューしてください。

- 電源・GNDシンボルが意図どおりに描画されているか。
- GND配線が不必要に長くないか。
- USBやXTAL信号がペアであると認識できるか。
- コンデンサと対応するICの関係が分かるか。
- 電源生成の流れを左から右に追えるか。
- 配線・文字・シンボルの重なりがないか。
- 電気的には非接続の交差を接続と誤認しないか。

必要に応じて再配置・再描画を繰り返してください。
