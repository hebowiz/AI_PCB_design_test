## R-0002 — 変更前後の負荷容量とコンデンサ

| 項目 | 変更前 | 一次対応後・今回維持 |
| --- | --- | --- |
| Y1 | ABM8-12.000MHZ-B2-T | ABM8-12.000MHZ-12-B1U-T |
| 指定負荷容量CL | 18pF（標準、容量指定なし） | 12pF（型番の-12） |
| C13・C14 | 各27pF | 各15pF、1%、C0G |
| 寄生容量の仮定 | 4.5pF | 4.5pF |
| 合成負荷の概算 | 27/2+4.5=18pF | 15/2+4.5=12pF |

負荷容量は外付けコンデンサ1個の値とは異なり、概算式は`CL ≈ C13*C14/(C13+C14)+Cstray`となる。変更前の27pFは、18pFの水晶に寄生容量4.5pFを仮定して選んだ値である。初回の`../../scripts/design.py`にも、この仮定と周波数・起動の測定が必要な旨が記録されている。初回スクリプトは参照のみで、再実行・変更していない。

FT232Hデータシートの27pFも例示であり、水晶メーカーの条件に合わせる必要がある。新水晶のCL=12pFに同じ寄生容量を仮定すると15pFとなる。1%・C0Gの採用理由は、公差と温度による容量変化を抑えるためである。実際の寄生容量を4.5pFと確認したわけではなく、いずれの値も実測前の初期値として扱う。PCBで全使用温度の発振周波数・起動・駆動レベルを確認し、必要なら容量を調整する。

根拠: [Abracon ABM8仕様・型番体系](https://abracon.com/Resonators/abm8.pdf)、[FT232H v2.2 §6.3](https://www.mouser.com/datasheet/2/163/DS_FT232H-3555343.pdf)。当該水晶をFTDI指定型番とは扱わない。今回Y1/C13/C14は変更していない。追加の「変更前の負荷容量と27pFの理由」という質問もR-0002に記録し、未判定を維持する。追加質問の送信時刻は取得できていない。
