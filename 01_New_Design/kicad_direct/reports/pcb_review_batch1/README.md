# A-2 PCBレビュー R-0017〜R-0027 修正候補

## 結果と変更範囲

USB・水晶、ICの引き出し、電源周辺を修正し、ビア寸法、同一ネット間の離隔、レジスト開口、サーマル接続を設定した。KiCad 10.0.8のERC・DRC・未配線・回路図との等価性エラーはいずれも0件。58部品の属性と197端子のネット接続は変更していない。

変更は広範囲に及ぶ。移動・回転した部品は34個。基準版の銅箔アイテム1167個に対し、UUID比較で973個を削除、713個を追加、8個を変更、186個をそのまま保持した。線分の分割・再作成も含むため、この数は変更面積ではない。基板全体の自動再生成は実施していないが、軽微な局所差分とは扱えない。配線とGND帰路を基板全体で再レビューする必要がある。

回路図、部品定数・型番・フットプリント、ライブラリ、既存生成スクリプト、BOM・製造データは保持。外形22×50mm、板厚1.6mm、2層、J1/J2/J3/SW1/SW2/SW3の位置・角度も保持した。BOM・Gerber・実装座標は今回のPCBに更新していない。固定Workspaceと既存設計ブランチは更新していない。

## 配置・配線の判断

USBの太い差動区間と水晶の短配線を優先し、Y1はU1の上側へ移動した。D1/D5はUSB線路に近接させ、短い枝で接続した。水晶周辺の空間を確保するため、FB1/FB2、DNPのC11/C12、R1、LED回路も移した。各電源の100nFを担当ピン側に置き、サイズの大きいC1/C2はその外側に配置した。

部品間・ビア間の離隔とパッド短辺中央の引き出しを優先したため、電源経路には迂回が残る。特にVPHYは、水晶引き出し直下のB.Cu横断を避けてU1側へ迂回した。GNDは表裏の元のゾーン外形を使い、充填し直した。狭いGND部分はビアと局所配線で接続したが、低インダクタンス帰路・電源インピーダンスを解析したものではない。

## USBインピーダンスの条件

KiCadが基準PCBから読み込んだ積層値は、FR-4のεr=4.5、誘電体厚1.51mm、表裏銅厚各0.035mm、表裏マスク厚各0.01mm、総厚1.6mm。元ファイルに明示的stackup節がなかったため当初見落としたが、KiCadの読み込み結果で確認し、修正版には明示保存した。製造業者による材料・公差の保証値ではない。[KiCadの積層実装](https://docs.kicad.org/doxygen/board__stackup_8cpp_source.html)も参照した。

この値で非被覆結合マイクロストリップの2次元準静的解析を行った。線幅0.8mm、端間隔0.2mm、銅厚0.035mmの場合、メッシュ幅0.01/0.005/0.0025mmでZdiffは89.7979/90.2259/90.3993Ω。`Zdiff = 2 / (c × sqrt(Codd × Codd_air))`を用いた。銅厚ゼロの独立照合はKirschning–Jansen式96.9057Ω、数値解96.4562Ωで差−0.464%。[式の参照](https://qucs.sourceforge.net/tech/node77.html)、[FTDIの配線指針](https://ftdichip.com/faq/when-routing-usb-signals-what-are-the-best-practices-for-protection-and-pcb-routing/)。

この約90Ωは一様断面だけの値。J1パッド、ESD枝、U1への0.15mmネック、0.3mmの裏面交差、2ビア、レジスト、有限幅GNDはモデルに含めていない。D+/D−の総銅箔線長は枝を含め7.9553/7.9967mmだが、D−の2ビア分の遅延を含まないため、電気的な等長を示さない。全経路の90Ω、USB信号品質、EMC、量産公差への適合は未確認。

直下層は全優先配線に対して銅箔の投影を検査した。ユーザーが許可したUSBペア同士の層切替部分以外に、他ネットの線・ビアの重なりはない。0.05mm以下の間隔で中心線を採点すると、水晶IN/OUTの178/152点は全てB.CuのGND充填上。USBではD+の14/168点、D−の23/145点が層切替のクリアランス部分にあり、連続した裏面GND上ではない。これは許可された交差に伴う制約として残した。

## 補助コードと経緯
