## 作図上の変更

全体を10の機能ブロックに分けた。上段にUSB入力、FT232H、レベル変換、外部端子、LEDを配置し、信号の流れを左から右へ読めるようにした。中段には発振・リセット・デカップリング、EEPROM、PWREN_N反転回路をまとめた。下段には固定3.3 V、可変VIO、ヘッダへの電源開閉を置いた。

同じ機能の抵抗・コンデンサを集め、局所的な接続を実線で示した。特に、U4の帰還抵抗とSW1、U5のDI/DOとR3/R4、Q1とR5/R6、U6と放電抵抗R16、LEDと直列抵抗を一続きに追えるようにした。デカップリングは電源別にまとめ、GNDを下側へ揃えた。長い交差配線を避けるため、機能ブロックをまたぐ一部の信号と電源はネットラベルを残した。

ラベル数は193個から130個へ減った。これは追跡箇所を減らした目安であり、読解時間を測定した値ではない。配線を0.1524 mm、分岐点を直径0.762 mmで描き、重複線は整理した。部品名・値・ネット名は1.27 mmへ揃えた。回転部品の文字、EEPROM電源線と部品名、フェライトやLEDの図形と文字の重なりは、PNGを拡大して修正した。

方向設定、Low有効信号、電圧切替、電源許可信号の関係を短い注記で説明した。注記は保存済み回路から読み取れる内容に限定した。型番やピン定義を修正するための作業は行っていない。

## 完全一致の確認方法

`before/netlist.xml`は回路図を編集する前に、`after/netlist.xml`は最終編集後に、同じ入力パスとKiCad 10.0.8で出力した。XMLの`design/date`は出力するたびに変わるため、この1項目だけを固定文字列に置き換えた。ネット名、端子、数値ネット番号、部品属性、ライブラリ定義、順序、ファイル名、UUIDは比較対象から除外していない。

前後の`netlist.normalized.xml`はバイト単位で一致し、SHA256もともに次の値だった。

`a53559ebd0b40a144d52449acd5f2b7ebd35cc6c8476bf99b462d8f3deff608a`

生のXMLは日時が異なるため、そのままのファイルハッシュが一致するとは扱わない。別のディレクトリで再出力するとXMLの入力パスも変わるため、再評価する場合も前後を同じパスで出力する。

回路図自体についても、シンボルごとの位置・表示設定だけを除いて比較した。部品の全プロパティ値、インスタンスUUID、各ピンUUID、ルートUUID、埋込みシンボル定義を照合した。既存ファイルはmainのGit blobと現在のGit blobを比較した。Gitで指定された改行規則を適用し、差分は0件だった。

## 再確認

保存済みの前後XML、回路図の属性、入力回路図のSHA256、既存ファイルの保全は、リポジトリのルートから次のコマンドで再確認できる。

```powershell
& "$env:LOCALAPPDATA/Programs/KiCad/10.0/bin/python.exe" 01_New_Design/kicad_direct/reports/schematic_v1/verify.py
```

`layout.py`は今回の配置編集を記録した補助スクリプトで、元の設計生成スクリプトから独立している。実行には`--apply`が必要で、保存済み出力と異なる編集がある場合は上書きを拒否する。人手で編集した回路図を再生成する用途には使わない。元の設計生成・配線スクリプトは実行・編集していない。既存のS式読書き補助モジュール`scripts/sexpr.py`のみインポートして使用した。

## 未解決事項

視認性の改善は、同じ表示条件での全体図と拡大図の目視評価に基づく。第三者設計者による読解時間や誤読率の測定は行っていない。

U1のシンボルは元の定義を保持したため、電源・GNDピンが片側に並ぶ構成は残る。A2全体を画面幅に縮小すると細かいピン名を読みにくく、拡大表示が必要になる。多ページ化やシンボルの機能別分割は今回実施していない。

USB差動配線、ヘッダの正式ランド寸法、EEPROM設定、実機動作など、元の設計で未検証だった事項は継続して残る。今回のERC合格はこれらの検証完了を意味しない。PCBと製造データは変更していないため、DRCや製造出力の再生成も行っていない。以前の`reports/schematic.pdf`などは過去の設計記録として保持し、今回の比較資料はこのフォルダに分離した。
