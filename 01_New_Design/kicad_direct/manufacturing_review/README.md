# 製造前レビュー用データ

**発注用リリースではない。** USB差動配線、J2/J3ランド、EEPROM設定などの未完了事項を[設計結果](../reports/result.md)で確認すること。

公称仕様はFR-4、2層、22 × 50 mm、板厚1.6 mm。銅厚35 µm/層、コア1.51 mm、マスク0.01 mm/面はKiCadの名目積層であり、製造業者と合意した条件ではない。表面処理も未指定。

`gerbers/`は両面銅箔・両面マスク・両面シルク・表面ペースト・外形、`drill/`はPTHとNPTHを分離したmm単位のExcellonと穴図。ドリルと実装座標の原点は左下の基板角。`positions_front.csv`には58部品を含め、USBコネクタも除外していない。全て表面実装側だが、コネクタの固定脚には貫通穴を使う。

`bom.csv`は設計部品表。実装業者固有の部品番号・供給可否・角度補正は未確認。ファイルのSHA256は`../reports/manufacturing_sha256.csv`。このフォルダはローカルで生成しただけで、業者への送信や発注はしていない。
