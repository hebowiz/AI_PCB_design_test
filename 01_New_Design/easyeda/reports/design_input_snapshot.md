# 概要
以下仕様に従い回路・基板を設計すること。
設計に使用するツールは別途指示する。

# 設計指示
## 回路概略
- 6Mbpsに対応したUSB-UART変換回路。
- UART側は1.8V/2.5V/3.3Vに対応。
- USB 5VからLDOを使って1.8V/2.5V/3.3Vを生成し、UART側のIO電圧とする。できればFB分圧比をSWで切り替えることで出力を変更できる仕様にしたい。
- UARTの各IO(フロー制御含む)、GND、USB 5V、LDO出力は面実装ピンヘッダで外部へ引き出せるようにする。
- TX/RXインジケータLED(緑)搭載。
- USB 5V接続インジケータLED(赤)搭載。
- LEDの輝度は直視しても眩しくない程度に抑える。
- USB 5VとLDOのピンヘッダ出力はSWでON/OFF可能にする。

## 部品選定方針
- 品番指定のないものは選定すること。
- 基本的に表面実装優先。
- 候補が複数ある場合は価格優先。
- 汎用CRは1005M優先。大きな容量が必要なCに関してはこの限りではない。

## 部品指定
- USB-UART変換：FT232H
- レベル変換：SN74AXC4T245
- USBコネクタ：ライトアングルUSB-Aプラグ(フレーム脚は基板貫通でOK)
- 電圧変換：FB分圧を外部回路で決定できるLDO
- SW：面実装スライドスイッチ
- LED：1608MサイズSMD
- その他汎用CR：選定は任せる

## 基板設計方針
- 外形サイズ：22mm x 50mm
- 基材：FR-4
- 板厚：1.0mm
- 層数：2層
- 全ての部品をA面に配置
- 片方の短辺にUSBコネクタを配置、反対側の短辺にGND/TXD/RXD/USB5Vの順でライトアングルピンヘッダを配置
- その他のピンヘッダは垂直タイプで一箇所にまとめる
- CAD上の向きは短辺がX軸方向となるよう設定
- 空きスペースはベタGND
- 部品リファレンスをシルク表示(小さめ)
