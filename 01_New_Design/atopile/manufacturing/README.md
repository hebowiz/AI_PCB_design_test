# 製造レビュー用データ

このディレクトリは製造承認前のレビュー用です。発注・外部転送は行っていません。最終判断の前に`../reports/design_review.md`の未解決事項を確認してください。

`review-only/`には銅2層、表裏レジスト・シルク、表ペースト、外形のGerber X2、PTH/NPTH Excellon、穴図PDF、BOM、実装座標CSVがあります。ZIPは同じファイルをまとめたものです。SHA256SUMSは出力直後の照合用です。

外形の中心線は22×50 mm、板厚は1.6 mmです。Gerber Jobの22.05×50.05 mmは外形線幅0.05 mmを含む境界値です。製品寸法を22.05×50.05 mmへ変更したものではありません。

CADの積層既定値は銅35 µm、誘電体1.51 mm、表裏レジスト各0.01 mmです。黒レジストとENIGもCAD既定値としてGerber Jobに入っています。工場と合意した積層、色、表面処理、コスト条件ではありません。USBのインピーダンスを含め、工場の実際の製造条件で見直してください。

PTHはビア穴0.25 mmが43、0.30 mmが3、USBシェルの0.70 mm長穴が2です。NPTHは0.90 mmが4、1.10 mmが2です。ビア中心が4か所の実装パッド内にあります。ビアの移動または充填・キャップ条件の確定前には製造へ進めないでください。

`placement.csv`はKiCadのフットプリント原点です。部品の吸着中心を保証する座標ではありません。特にUSBプラグと独自の横出しヘッダーは、実装工場向けに中心と回転を確認する必要があります。USBの負のY座標は基板端から外へ出るプラグの原点によるものです。

BOMは候補型番を1行1部品で記載した51行です。実装サービス固有の在庫番号・価格・購入代替を承認したものではありません。KiCadの全51部品の座標を出力し、シェルがPTHのUSBプラグも除外していません。
