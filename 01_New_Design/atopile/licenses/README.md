# フットプリントの出典と変更

`board/parts/`の標準フットプリントは、インストール済みKiCad 10の公式ライブラリからコピーしました。元のライブラリ名とフットプリント名は`reports/bom.csv`に記載しています。著作権はKiCad Library Contributorsおよび各ファイルに記載された権利者に帰属します。配布条件は[KiCad-LICENSE.md](KiCad-LICENSE.md)のCC-BY-SA 4.0と設計ファイルに対する例外です。

`JS203011SCQN`と`TSM_104_SH`は、メーカー寸法図を参照して今回作成したフットプリントです。これらもこのライブラリ集ではCC-BY-SA 4.0で提供します。メーカー資料の画像やPDFは同梱していません。

`board/A1.pretty`は上記のフットプリントから作成した部品別の派生ファイルです。シルク図形をDwgs.Userへ移し、部品番号を表面または裏面へ配置しました。U1.4、U2.3、U3.5、U3.7、C14.2はGNDゾーンへ直接接続する設定です。パッド番号、位置、寸法は元のフットプリントと同じです。派生ファイルにも同じライセンス条件を適用します。

pcb-pipelineスキルは実行時に参照しましたが、スキル本体やMITライセンスには変更していません。
