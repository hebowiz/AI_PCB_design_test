# 次期検証：設計指示による品質改善

記録日：2026-11-19 JST
状態：**検討案・未実施**。ユーザーによる初回設計レビュー、CAD修正、追加設計は後日実施する。

## 背景と観察

初回A-1（atopile+KiCad）・A-2（KiCad単独）・A-3（EasyEDA Pro）は、共通仕様から回路図・PCB・製造レビュー用データの生成まで完走した。一方、回路図の視認性、レイアウト重要部の設計優先順位に改善余地がある。USB High-Speedの90Ω差動インピーダンス管理が必要なことをCodexは未検証事項として認識・報告したが、それを配置・配線の初期制約として工程に組み込んだことは確認できていない。

### 課題の分類

1. **回路図の視認性**：ネットリストとしての接続合致とは別に、人間が機能ブロック、電源の流れ、信号方向、部品の役割を追える必要がある。特にA-1は矩形シンボル中心で、見やすい回路図としての意図的なレイアウトは不十分。A-2/A-3も人間の正式レビューは未実施。
2. **基板配置と優先順位**：明示条件はある程度反映されたが、未指示の重要制約（信号品質、電源帰路、発振回路、熱、EMC、機械寸法など）を自発的に洗い出し、配線順序・部品位置へ組み込む能力は未確認。
3. **認識と実行の乖離**：「この制約が必要だと知っている」ことと「設計開始前に必要情報を調査して制約を設定し、実配線で遵守した」ことは別の能力。ERC/DRC合格や最終報告の注意喚起だけでは後者を検証できない。

## 検証の狙いと仮説

**H1：回路図作成時の要求・評価基準を明示すると、接続を変更せずに視認性を改善できる。**

- 元のA方式の成果物を読み取り専用の基準とする。
- **V0（初回）**：保存済み回路図の視認性評価。
- **V1（簡潔な指示）**：「人間がレビューしやすい回路図にする。機能ブロックごとに配置して信号の流れを示す」程度。
- **V2（評価基準つき）**：電源→主IC→レベル変換→外部IO等の機能別整理、適切な標準シンボルの採用、ブロック内配線とブロック間ネットラベルの使い分け、信号方向、部品定数、ページ分割、文字重複・交差の抑制、画像出力と自己レビューを求める。
- 指標：接続一致、ERC、標準シンボル利用の適切さ、各機能の追跡しやすさ、ラベル/文字の衝突、必要なレビュー時間、修正に要した作業時間。
- **重要**：自動採点だけで「見やすい」と断言しない。最終判断は設計者のレビューとする。

**H2：設計開始前の重要制約抽出・優先度付け・通過条件を指示すると、重要部のレイアウト品質を改善できる。**

- **V0（初回）**：USB差動・発振・電源・実装上の課題を後から報告した既存設計。
- **V1（一般原則）**：「重要な信号・電源・機械的制約をデータシートに基づき優先して設計する」とだけ指示する。
- **V2（工程ゲート）**：設計前に重要ネット・制約・出典・未確定情報を列挙し、優先度に従って部品配置→重要配線の固定→その他配線→ERC/DRC→特性上の再確認を行う。重大な条件が未確定なら、適当に完了扱いせず暫定設計と明記する。
- 比較条件を揃えるため、まずは一つの方式でV0/V1/V2を比較し、効果があれば他方式でも同じ要求と評価項目で試す。
- 指標：重要条件の抽出率、制約の設定時点、差動配線の幾何・ビア・長さ・帰路、発振子周辺の配線構造、規則設定と検証結果、再配線・手戻り、設計時間。

### USB差動配線の具体例

USB 2.0 High-Speedの差動インピーダンスは**目標約90Ω**。実現には製造業者のスタックアップ（誘電体厚・比誘電率・銅厚・ソルダーレジストなど）の確認と線幅・間隔の設計が必要。CADのDRCだけで実インピーダンスを保証することはできない。

検証では、以下の**設計工程**を観察する。

1. FT232HのUSB信号の要件とメーカー推奨レイアウトを認識する。
2. スタックアップと信号層/GND基準面を確認する。未指定なら暫定仮定を明示し、人間判断が必要な点を分離する。
3. 差動対の概算寸法とルールを設定する。コネクタ・ESD素子・ICを優先配置する。
4. USB D+/D−をGND帰路、長さの非対称、層変更、ビアの不一致、スタブを考慮して先に配線する。
5. 他の自動配線が優先配線を壊さないように固定・保護する。
6. DRCとは別に、幾何・予測インピーダンス・未検証事項をレポートする。

**規則は万能ではない**：明示的な「90Ω優先」の一文だけで実装保証にはならない。製造スタックアップ未確定なら電磁界解析や製造先のインピーダンス計算を含めて扱う。

## 実験設計上の注意

- 初回成果物のCAD、製造データ、ログ、ブランチを保存する。追加試験は別ブランチ・別フォルダで行い、ベースラインを上書きしない。
- **回路図の改善とPCB配置優先度の改善を同時に指示しない**。何が効果をもたらしたか不明になるため、評価の軸を分ける。
- 指示の詳細化はAIの本来の自律判断能力を測る条件を変える。V0（初回）とV1（抽象的な品質要求）を先に比較し、V2（具体的な工程制約）は上限性能として比較する。
- A-1/A-2/A-3は部品/フットプリント/使用CADや配線器が異なる。方式間の比較では、プロンプトだけの差と設計条件の差を区別する。
- レビュー時間・追加指示回数を記録。人間が具体的に修正内容を教えることを「AIの自主的な発見」として集計しない。
