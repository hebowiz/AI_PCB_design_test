# 技術レポート構成案

## 1. 目的と背景
AIによる回路・基板設計の自動化と人間・AI協調設計の可能性を評価する。

## 2. 試験環境
OS、Codex、KiCad、atopile、Freerouting、Java/Python、ソフトウェアの版、構築手順と制約。

## 3. 試験A: 3設計手段による新規設計（A-1/A-2/A-3）
共通要求仕様を使用し、A-1 atopile+KiCad、A-2 KiCad直接、A-3 EasyEDA Proを比較。指示文、回路設計・部品選定、配置・配線、ERC/DRC、製造データ、手修正と課題を各方式ごとに記録。

## 4. 試験B-2: KiCad既存設計の修正（手段2のみ）
元回路・PCBと保護対象、修正指示、変更前後差分、設計の保護、人間レビューと再引継ぎ。

## 5. 共通評価項目
| 指標 | 内容 |
| --- | --- |
| 設計工数 | AI処理時間と人間操作・レビュー時間を別々に記録 |
| 手動介入 | 回数・内容・理由 |
| 生成品質 | 部品選定、ERC/DRC、製造可能性 |
| 差分保全 | 指定範囲外の部品・ネット・パターン変更の有無 |
| 性能確認 | 回路解析、RF/EMC、熱、実機測定の有無と結果 |
| 再現性 | 指示、ソフトの版、入力・出力・再実行結果 |
| 運用性 | 手戻り、保守・学習コスト |

## 6. 考察
atopile+KiCad対KiCad単独対EasyEDA Pro、AとBの評価対象の違い、人間が担う設計領域。

## 7. 結論
適用可能な範囲、未解決課題、改善ロードマップ。
