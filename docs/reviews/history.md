## 2026-11-26 21:16 JST — PCB配線品質の追加ルールを受付

指摘者：ユーザー。対象：A-2、`codex/a2-r0035-usb-edge`、`ca191ab2a900714d53f7ab0eb8984b58f3af7ef8`。固定Workspaceの参照コミットも同じ。以下は要求の登録であり、現物の違反検出結果ではない。全5件を未着手・未判定とし、既存指摘の状態・判定は変更しない。

<a id="r0036-collection-01"></a>
### R-0036 — 鋭角銅箔と途中分岐

配線・分岐部の銅箔輪郭の内角が90°未満となる形状を禁止する。分岐は可能な限りパッドまたはビアから行い、配線途中の分岐を最小化する。やむを得ない途中分岐には補助線分を追加し、鋭角を避け、鈍角または自然な形状とする。

関連：R-0024・R-0029の配線形状、R-0030の分岐構成。今回は中心線の曲がりとは別に銅箔輪郭を対象とする追加要求。重要度Majorは要求仕様・配線品質への影響を踏まえた受付時の暫定評価。

<a id="r0037-collection-01"></a>
### R-0037 — 実質直角配線

見かけ上45°線分を含んでいても、実質的に90°方向転換となる配線を禁止する。方向転換は自然な45°配線で構成し、短い線分を挟んだだけの疑似直角を避ける。ICパッド短辺から引き出した後も、不自然なL字・階段状配線を作らない。

関連：R-0024・R-0029の方向転換、R-0025のパッド引き出し。既存判定を変更せず、今回の実質形状に関する追加基準を新規管理する。「短い」「実質直角」の数値的な検出条件は未定義であり、調査時に提案する。重要度Minorは局所的な配線形状改善としての暫定評価。

<a id="r0038-collection-01"></a>
### R-0038 — ビア数・層切替の最小化

明確な設計意図がない限り層切替とビア数を最小化する。追加ビアは信号品質、GNDリターン、配線制約、熱・電流分散などの合理的理由がある場合に限り、単に配線しやすいという理由では追加しない。GNDベタのビアはこの制限の対象外とする。

関連：R-0017のUSB差動配線と最小限の交差ビア、R-0018〜R-0020のビア寸法・離隔、R-0028の経路合理性。重要度Minorは設計意図と配線効率の確認としての暫定評価。

<a id="r0039-collection-01"></a>
### R-0039 — GNDベタの細線・半島・オープンスタブ

接続先のない半島状・ひげ状・行き止まり状のGND銅箔を残さない。GNDベタの有効幅1.0mm未満となる細い接続部は原則禁止とし、必要最小限の例外を除いて解消する。半島化しそうな領域はGNDビアで反対層と接続し、GND面の連続性を高める。チップ部品パッド間などの細いGNDベタで、設計上の意義が薄いものは除去する。

関連：R-0017・R-0026の直下GND、R-0023のサーマル、R-0030のオープンスタブ。既存の信号配線グラフと区別して、GNDベタの形状・有効幅を対象とする。例外箇所は未選定。重要度MajorはGND面の連続性と帰路への影響を踏まえた暫定評価。

<a id="r0040-collection-01"></a>
### R-0040 — 品質検証と修正前後の拡大画像

ERC、DRC、未配線、回路図整合性に加えて、鋭角銅箔の有無、実質直角配線の有無、配線途中分岐の件数、ネットごとのビア数、GNDベタの細線部・半島部・オープンスタブの有無を確認する。修正前後の拡大画像を提示し、人間が視覚的に確認できるようにする。

関連：R-0036〜R-0039および既存PCB検証。重要度Majorは今回の追加要求に対する検証証跡としての暫定評価。将来の結果は固定成果物のmetrics.json等とdetails.png・comparison.pngへ集約し、レビュー別フォルダは作らない。

今回の受付では詳細調査・CAD修正・検証を開始しない。一括調査の指示を待ち、修正はユーザーが承認した範囲で行う。
