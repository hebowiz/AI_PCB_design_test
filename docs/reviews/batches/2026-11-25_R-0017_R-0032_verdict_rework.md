# PCBレビュー判定と残件の再修正

日時：2026-11-25 00:18 JST / ユーザー
対象：`codex/a2-pcb-quality-r0028-r0032` / `87711e88e10653e79fdce9c3ade341b8f1440489`

## 判定

R-0017〜R-0023、R-0025、R-0026、R-0028、R-0030〜R-0032はOK。R-0028は一旦OKとし、他の修正後に必要なら別途起案する。

R-0024・R-0029は直角配線が複数残るとの再指摘。R-0027は小容量コンデンサの配置は概ねOKだが、大容量コンデンサの位置と配線インダクタンスに問題が残る。電源→大容量コンデンサ→小容量コンデンサ→入力ピンの順で給電し、コンデンサからGNDまでの配線を最短化する。

ユーザーは残件の再調査と修正を依頼した。NGという明示判定はないため、残る3件は対応中・未判定とする。以前の判定は過去のバッチに保持する。

## 修正範囲

`codex/a2-pcb-corners-decoupling`を対象コミットから作成。固定Workspace・既存設計ブランチ・回路図・部品定数・BOM・製造データを保護し、PCBの曲がりとコンデンサ周辺の配置・配線だけを修正する。パッド・ビア・分岐点に隠れた曲がりを含め、基板全体を再検査する。承認済みUSB差動配線やコネクタ配置を維持し、水晶は必要な角処理のみ行う。
