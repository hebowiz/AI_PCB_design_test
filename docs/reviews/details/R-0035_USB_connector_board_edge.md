# R-0035 — USBコネクタと基板端の位置確認

指摘日時: 2026-11-25 20:50 JST / 指摘者: ユーザー。
対象: A-2、PCB、J1（USBコネクタ）と基板外形、codex/a2-r0034-header-layout、5cce544232e1f0eb137ef95f5060eeea5c9729ef。

## 指摘内容

USBコネクタと基板外形の間に隙間があるように見える。基板端に対するコネクタの位置が正しいか確認したい。

## 受付範囲

指摘収集として登録。隙間の有無・位置の適否は未調査で、修正・検証は実施していない。R-0034のOK判定とは分けて管理する。

## 調査 — 2026-11-25 21:00 JST

対象は固定Workspaceの5cce544232e1f0eb137ef95f5060eeea5c9729ef。KiCad 10.0.8のpcbnewで座標を読み取り、Molex公式図面とローカルの公式由来STEPを照合した。結論は、**J1の現行位置はメーカー推奨基板端位置に一致せず、基板外側へ0.60mmずれている**。J2で起きたモデル設定の未保存とは異なり、J1はパッド・位置決め穴を含むフットプリント自体の配置差である。

### メーカー図面と現行配置

対象型番はMolex 0480372200（48037-2200）。[製品ページ](https://www.molex.com/en-us/products/part-detail/480372200)のUSB Type-A SMTプラグで、推奨基板厚1.60mmの品種。[公式寸法図](https://www.molex.com/content/dam/molex/molex-dot-com/products/automated/en-us/salesdrawingpdf/480/48037/480372200_sd.pdf)の推奨PCBレイアウトを確認した。ローカル確認資料はSD-48037-004、Rev D、2015-11-05、材番48037-2200。位置決め穴中心から基板端までの参照寸法は2.75mm、同じ中心線から信号パッド中心まで2.60mm。基板端をコネクタのシェル端へ直接合わせる指定ではない。

| 項目 | 現行 | 推奨位置へ合わせる案 |
| --- | --- | --- |
| 基板端 | Y=100.000mm | 変更なし |
| J1原点 | X=111.000、Y=93.775mm、90° | X=111.000、Y=94.375mm、90° |
| フットプリントのPCB Edge補助線 | Y=99.400mm | Y=100.000mm |
| 位置決め穴・シールド穴中心列 | Y=102.150mm | Y=102.750mm |
| 信号パッド中心列 | Y=104.750mm | Y=105.350mm |
| 位置決め穴中心から基板端 | 2.150mm | 2.750mm |

パッドと穴の内部寸法関係は、端位置確認に使った範囲では推奨図と整合する。PCB Edge補助線はDwgs.User上の線で、Edge.Cutsではない。単にDRCを通しても、この補助線と基板端の0.60mm差は検出されない。[座標証跡](../evidence/R-0035/geometry.json)と[配置比較図](../evidence/R-0035/placement_comparison.png)を保存した。

既存の生成スクリプトscripts/design.pyのREVISEDにもJ1=(11,-6.225)があり、基板座標のオフセットを加えた現行位置と一致する。初回設計からの座標指定が後続版へ継承されたことを確認した。0.60mmを意図して設けた理由は、確認した記録では見つからない。推奨基板端との照合が不足していたと考えるが、当時の判断理由は断定しない。

### 3Dで見える隙間

現在のPCBから[側面画像](../evidence/R-0035/current_side.png)を新規出力し、[拡大画像](../evidence/R-0035/current_side_detail.png)でも隙間を確認した。J1の保存済みモデル倍率は1、回転・オフセットは0。Molex公式由来の座標変換済みSTEPを使っている。

FreeCADで基板厚内の中心断面（モデルY=±0.01mm、Z=-0.81〜-0.79mm）を調べると、コネクタ側の境界はPCB座標Y=99.20mm、基板端はY=100mmで、断面上の隙間は約0.80mmとなる。J1を0.60mm内側へ移すと、同じモデルでは約0.20mm残る計算になる。[断面計算](../evidence/R-0035/model_section.json)。

この0.20mmは現行STEPの公称形状から求めた値であり、メーカーが保証する組立隙間や公差とは扱わない。見た目の隙間をゼロにするため0.80mm動かすと、推奨基板端位置を0.20mm越えてしまう。モデルを変形・移動して隙間だけを消す方法も採らない。

### 対応案と影響

推奨案は、外形22×50mmと板厚1.6mmを維持し、J1全体を基板内側（+Y）へ0.60mm移すこと。コネクタの型番・ランド寸法・回路接続は維持する。USB_D+/D-、USB5V、GND、シールドの接続は端子側の局所配線修正が必要になる。

現行Courtyardを幾何学的に0.60mm平行移動して比較したところ、D1・D5・Y1・C14・C12の5部品と重なる。これは実装領域の重なりで、実部品の衝突を断定するものではない。C12は既存のDNP部品だが、今回の調査で除外やDNP条件は変更していない。銅箔パッドの矩形包絡による予備計算では、信号パッドとD1/D5の間は約0.40mm、J1.4とY1.3の間は約0.25mm残る。配線・はんだ・機構公差を含む適否は修正候補で再検証する必要がある。

修正範囲はJ1と上記周辺部品・関連配線の局所調整を候補とする。5部品すべての移動が必要と確定したわけではない。水晶と負荷容量の近接、USB差動線の対称性・幅/間隔・GNDリターン、ESD分岐、USB5V幅を維持する。DRC除外追加や根拠のないCourtyard縮小だけで解消扱いにしない。基板端だけを0.60mm延長する案は外形寸法を変え、基板全体の移動はJ2端合わせへ影響するため推奨しない。
