# R-0016 — USB5V_OUTの0Ω直列抵抗・測定TP追加

指摘者はユーザー。指摘日時は2026-11-22 22:20 JST。対象は`codex/a2-review-reset-flags`、`fa741e9e1f7853efc5d27d3cb2c969a86abb31a1`。

SW2とJ2.4間に1608M（0603）の0Ω抵抗を直列追加し、通常は0Ωを実装する。将来のPPTC交換を検討できるよう、推奨ランドパターンを比較して可否を確認する。0Ω自体には過電流保護機能がない。平均負荷10〜20mA、瞬時最大約50mA。0Ωの両側に約Φ1.5mmのテストポイントを追加する。

ユーザーは調査と、問題がなければ回路図への追加・ネットリスト差分・ERC・作図検証まで承認している。既存レビュー済み設計は別ブランチで保護し、PCB・BOM・製造データは変更しない。

## 調査・選定

Codexが調査中・未判定で着手。設計前提は`d6a3bcfd055e50aaca30caef71cbc277253537de`。保護ICの検討案は未確定だった。

通常実装用にBourns CR0603-J/-000EPFを選定した。0603、ジャンパ定格1A、最大抵抗50mΩ。瞬時最大50mAでの抵抗単体の計算上限は2.5mV・0.125mW。0Ω自体に過電流保護機能はない。

PPTC候補はMF-FSMF020X-2とMF-FSMF010X-2。前者は23℃のIhold 200mA・Itrip 500mA、85℃のIhold 70mA。後者は23℃のIhold 100mA・Itrip 300mA、85℃は30mA。パルス継続時間・環境温度・短絡電流が確定していないため、PPTCの正式採用は保留とする。

推奨ランドの比較では、R17に割り当てた抵抗用ランドは内側間隔0.80mm・幅0.90mm。PPTC推奨は間隔1.00±0.05mm・幅1.00±0.05mmで、共通推奨範囲がない。判定は「メーカー推奨ランドとしての直接交換互換なし」。将来検討用の直列挿入位置とTPは設けたが、PPTCへ無条件に差し替え可能とする要求までは達成していない。採用時はメーカー確認・実装試験による共通ランド認定、またはPCB設計時のランド変更が必要。

根拠は[Bourns CR-PF REV.07/20](https://www.bourns.com/docs/product-datasheets/cr-pf.pdf) p.1・3と[MF-FSMF REV.K 09/26](https://www.bourns.com/docs/product-datasheets/mf-fsmf.pdf) p.1〜3。メーカー原本は転載せずURLと取得SHA256を記録した。PPTCのトリップは精密電流制限ではなく、今回の0Ω追加で過電流保護やUSB電流予算の検証が完了したとは扱わない。

## 対応と検証

ユーザーの「問題がなければ回路図への追加」に従い、通常の0Ω実装に問題がない範囲を実施した。承認済みfa741e9から専用ブランチを作成し、R17とTP1・TP2を追加。R16は削除履歴があるため再利用しなかった。

SW2.2→USB5V_SW→R17.1 / R17.2→USB5V_OUT→J2.4とし、TP1は上流、TP2は下流に分岐。測定時はR17を外し、TP間へ電流計を直列接続する。既存FLAGは上向きのままR17下流へ移した。図面には通常0Ω、保護なし、想定負荷、測定手順、PPTC交換未認定を記載した。

R17用メーカー推奨中間寸法ランドと径1.5mmの標準TPランドを新規追加し、標準Connectorシンボルライブラリを登録した。既存ライブラリ定義は不変。TPは基板銅箔としてon_board=yes、別体部品ではないためin_bom=no。既存BOMファイルは変更していない。

## 検証・証跡

- ネットリストは55→58部品、193→197端子、54→55ネット。既存端子の変更はSW2.2だけで、R17両端の分割に一致。ほかの既存接続・属性・UUID・ピン定義を保全。
- ERCは前後ともエラー0・警告0。同一設定で既存4除外を維持し、追加除外なし。
- 全FLAG上向き、既存コンデンサ縦向きで不変、重複線分・重なり0。全体図・電源ブロック・変更箇所・J2拡大図を確認し、3回の出力でTP文字重なりと注記位置を改善。
- PCB・BOM・Gerber・元生成スクリプトを含む既存589ファイルのGit blob一致。Windowsの既存改行変換を正規化して照合。出力18ファイルのSHA256を確認した。
